# Google File Manager

A standalone tool to list and delete files uploaded to Google File API (Gemini).

## Usage

```bash
python google_file_manager.py
```

This will:
1. Read your Gemini API key from the Ebook-Translator plugin config
2. List all uploaded files
3. Let you select files to delete

## Requirements

- Calibre must be installed (to read the plugin config)
- A Gemini API key configured in the Ebook-Translator plugin
